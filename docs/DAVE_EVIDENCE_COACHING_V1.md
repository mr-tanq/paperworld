# Dave — Evidence-Based Coaching V1

Dave remains the **private Wellbeing Director**. This implementation gives him a
stable, source-aware coaching reference on strength training, gym programs, movement,
physiotherapy literacy, pain-aware activity, healthy weight gain and nutrition.

## How it works
- `server/dave-coaching-guide.cjs` returns a bounded reference instruction.
- The guide enters only Dave's **direct conversation** or an **explicitly
  consented Matt → Dave conversation**. Other Directors do not receive it.
- Approved Wellbeing memory remains owner-scoped, private and historically
  contextual. **Do not put any personal medical details in this Git repository.**
- Guide is knowledge, **not** clinical examination, personalized diagnosis,
  medical clearance, live web search, monitoring, autonomous scheduling, or an
  extra AI call. No new Supabase migrations, credits, cron, or worker grants.

## Coaching workflow
1. Clarify goal, recent activity, equipment, recovery and clinician restrictions.
2. Offer a practical low-to-moderate training structure adaptable to three
   nonconsecutive weekly sessions, with gym/home alternatives.
3. Show exercise technique, sets/reps/rest, progression and manageable
   pain/symptom monitoring; defer injury-specific load decisions to treating physio.
4. Provide realistic meals and evidence-aware protein/energy context without
   rigid calorie or supplement prescriptions.
5. Reassess the plan using the user's progress and approved private history,
   not guesses about current pain or clearance.
